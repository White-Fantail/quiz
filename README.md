# Clupio (클루피오)

**Follow the clues. Find the fun.**  
단서를 따라, 재미를 발견해.

Clupio is an open quiz platform for creating, discovering and playing clue-based games.

> This repository is being initialized. Active development takes place on `dev`; `main` is the stable branch.

## Development rules

- Work on `dev` by default.
- Merge only with fast-forward (`git merge --ff-only`).
- Do not merge into `main` without an explicit request.
- Keep question difficulty, creator audience intent and platform-assessed safety as distinct concerns.

See the `dev` branch for the evolving project structure.
