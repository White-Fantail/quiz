# Implementation roadmap

- **Phase 0 — Foundation (this scaffold):** repository setup, Git rules, TypeScript domain model, branded responsive web entry points, example clue game, health/demo API, tests and CI.
- **Phase 1 — Platform core:** database and migrations, authentication/creator permissions, actual content API, versioning and upload strategy.
- **Phase 2 — Play experience:** game rules, progressive clues, answer validation on server, score, image clues and packs.
- **Phase 3 — Open creation:** Studio editor, publication pipeline, AI-suggested category/audience/difficulty, reports and reactions.
- **Phase 4 — ChatGPT:** authenticated Remote MCP tools for draft/edit/preview/publish/manage, explicit author intent and abuse safeguards.
- **Phase 5 — Kids + multimodal:** automated safety classifications, safe Kids exposure, image reveal, audio/video/map support.
- **Phase 6 — Community:** creators, stats, recommendations and new modes.

**Next vertical slice:** define persistence/auth and implement one real draft → preview → publish → play loop before adding more game styles.
